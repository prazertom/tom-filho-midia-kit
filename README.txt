# Tom Filho — Mídia Kit 2026 · V2

Esta versão reaproveita a direção visual e a home do index.html de referência enviado pelo usuário, mas reorganiza todo o conteúdo com base no PDF do Mídia Kit 2026.

Arquivos:
- index.html
- style.css
- script.js
- assets/

Os assets são imagens extraídas diretamente do PDF.

Para publicar no GitHub Pages:
1. Envie index.html, style.css, script.js e a pasta assets para a raiz do repositório.
2. Settings > Pages > Deploy from a branch > main > / (root).
3. Salve e aguarde a publicação.
